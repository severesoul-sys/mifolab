Кто кого побеждает

7 стихий

Строка — стихия удара. Столбец — стихия защищающегося. У двухстихийного духа множители защиты перемножаются; обычный удар идёт первой стихией, Ультра — второй.

Покрытие ваших отрядов

Числа — сколько духов бьют данную стихию усиленно обычным ударом / Ультрой и сколько уязвимы к ней. Это оценка покрытия, а не прогноз победы.

Как пользоваться Mifo Lab

Арена. Выберите духов для сторон A и B, задайте уровень, IV, нрав и качество рун. Рассчитайте один бой или серию, чтобы сравнить команды.

Мои духи. В приложении для Android подключите аккаунт по коду из профиля игры и нажмите «Получить духов из подворья». Следующие обновления выполняются только по кнопке «Обновить духов». Сохранённый список доступен офлайн.

Рейды. Выберите босса, количество игроков и отряды. Можно подобрать команду из своих духов и оценить вклад каждого участника.

Тренировка рун. Обведите выбранный узор пальцем или мышью. Начните без таймера, затем попробуйте нарисовать руну за время боя.
