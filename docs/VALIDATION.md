# Проверка исходников 1.0.4

20 октября 2026 года самостоятельный проект проверен на Windows с Node.js 24, JDK из Android Studio и Android Build Tools 36.0.0.

- Debug APK успешно собран из этого дерева исходников с отдельным локальным ключом разработки.
- Все 24 веб-ресурса APK совпадают по SHA-256 с установочной версией Mifo Lab 1.0.4.
- На отдельном эмуляторе Android прошли **105 инструментальных проверок**: навигация, поиск, арена, рейды, рейтинги, подворье, подбор команды, рисование рун, защита токена и офлайн-восстановление.
- Без локальных эталонных клиентов проходят **29 основных тестов**; четыре дополнительных теста явно пропускаются. С локально предоставленными клиентами Mifozov 0.37 и 0.42 проходят **все 33 теста**.
- Клиенты игры и реальные данные аккаунтов не включены в репозиторий. Проверки подворья используют синтетические данные.
- Проверены состав отслеживаемых файлов, отсутствие ключей подписи и паролей, отсутствие зависимостей сборки от соседних проектов.
