# Проверка Mifo Lab 1.3.0

- 49 тестов Node.js прошли, включая 276 сравнений рейдов с клиентом 0.46, проверки бонуса дружбы, локальных отрядов и вместимости Подворья. Пять исторических сравнений пропущены без соответствующих файлов клиента.
- В браузере проверены сохранение шести духов, перенос отряда между сторонами арены и рейдом, расчёт рейда с бонусом 15%, отображение расхода зелий и восстановление настроек.
- Упакованный мобильный интерфейс проверен при 360×640 с тестовым мостом аккаунта: Подворье 10 из 350, максимум 500; горизонтального переполнения нет. Арена и кнопка расчёта помещаются над нижней навигацией. Ошибок JavaScript не обнаружено.
- Android-код скомпилирован. Новые инструментальные проверки добавлены, но в этом выпуске не запускались: среда проверки не предоставила доступ к adb. Нативное скрытие системных панелей и работу с вырезом камеры следует дополнительно проверить на устройстве.
- Бонус дружбы — явно обозначенный оценочный сценарий. Применение и округление бонуса на сервере 0.51 не проверены реальным боем; базовые расчёты при нулевом бонусе сохраняют совпадение с эталоном 0.46.
