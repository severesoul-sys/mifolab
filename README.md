# Mifo Lab

Симулятор боёв духов для [Mifozov](https://mifozov.com): подбор команд, рейды, рейтинги и тренировка рун. Работает на Android и в браузере компьютера.

**[Скачать APK для Android](https://github.com/severesoul-sys/mifolab/releases/latest/download/mifolab.apk)** · [Что нового](https://github.com/severesoul-sys/mifolab/releases/latest) · [Сборка приложения](docs/BUILD.md) · [Графика и данные](THIRD_PARTY_NOTICES.md)

Требуется Android 8.0 или новее. APK из Releases можно устанавливать поверх предыдущих официальных версий Mifo Lab с сохранением настроек и подворья.

Постоянная ссылка скачивает `mifolab.apk` из актуального выпуска. Версия хранится внутри приложения; название установочного файла не меняется при обновлениях.

## Возможности

- **Арена:** бои 1 на 1 и 6 на 6; уровень, IV, нрав, Живица и ручная настройка характеристик; один бой или серия.
- **Рейтинг духов:** 138 видов текущей летописи, сравнение по мощности и результатам 604 992 боёв кругового турнира.
- **Рейды:** боссы, команды до шести игроков, лучшие атакующие, подбор команды из собственных духов; Отвар силы и до двух применений Живой воды на участника.
- **Мои духи:** личный рейтинг пойманных экземпляров и их назначение на арену или в рейд.
- **Планировщик усиления:** стоимость в Пыли и Искрах, характеристики на каждом уровне, предел по уровню игрока и запасам. Доступен из рейтинга и карточек собственных духов.
- **Руны:** рисование мышью или пальцем, оценка точности, занятия с таймером и без него.
- **Справка:** преимущества стихий и покрытие отряда.

Поиск принимает имя, прозвище и номер летописи. Например, `006` или `№006` находят Рарога. Два пойманных духа одного вида сохраняют отдельные характеристики.

Версия 1.3.0 добавляет именованные отряды, оценку бонуса дружбы в рейдах, вместимость Подворья и полноэкранный режим Android. В каталоге 138 видов с номерами 001–138. Архивные пойманные духи остаются доступны для расчётов, а общий рейтинг строится по текущей летописи.

Кнопки **«Отряды А»**, **«Отряды Б»** и **«Мои отряды»** в рейдах открывают общую библиотеку до 30 составов. Назовите отряд и сохраните текущие места и характеристики. Для обновления выберите «Заменить текущим». Библиотека хранится на устройстве; после изменения духов в игре сохранённый состав обновляется вручную.

В рейдах блок **«Бонус дружбы»** задаёт 0–15% для всех участников. Это оценочный сценарий: выбранный процент прибавляется к урону по боссу, точное округление игры может отличаться. В одиночном рейде бонус отсутствует. Вклад дружбы показан отдельно; выбранные условия учитываются в рейтинге атакующих, подборе состава и оценке количества игроков.

Кнопка **⛶** в верхней строке Android-приложения включает и выключает полный экран. Выбор сохраняется.

В «Рейдах» раскройте **«Зелья для рейда»**. Отвар силы даёт +10% к Силе каждого духа, не меняя Дух и Ультру. Живая вода восстанавливает 50% максимальной Живицы и сохраняет энергию. По умолчанию зелья выключены. Выбранные условия применяются к каждому участнику, рейтингу атакующих и подбору отряда.

Автоматическая тактика симулятора использует Живую воду, когда выбыл весь отряд, и возвращает духа с первого места. Переставьте нужного духа вперёд; время применения задаётся временем смены и должно быть меньше десяти секунд. В игре игрок сам выбирает время и цель — другая тактика может дать другой результат. Запасы зелий задаются вручную; приложение ничего не расходует.

## Подворье и офлайн-работа

В Android-приложении откройте «Мои духи», введите код из профиля Mifozov и нажмите «Подключить». Чтобы получить список, отдельно нажмите **«Получить духов из подворья»**; в дальнейшем — **«Обновить духов»**.

Открытие приложения и подключение аккаунта не обновляют подворье автоматически. Сохранённый список и расчёты доступны офлайн. Отключение аккаунта удаляет данные входа и оставляет сохранённых духов для расчётов.

При ручном обновлении вместе с духами сохраняются уровень опыта игрока, запасы Пыли и Искр для планировщика, заполненность и вместимость Подворья. Базовая вместимость — 250, расширения по 50, максимум 500 мест. В старых копиях вместимость показывается как неизвестная до следующего ручного обновления.

## Планирование усиления

В «Рейтинге духов» нажмите **«Планировщик усиления»** и найдите духа по имени или номеру летописи. Задайте начальный и целевой уровни, IV и нрав. В «Моих духах» кнопка **«Усиление»** сразу открывает конкретный пойманный экземпляр с его настоящими параметрами.

План показывает общую стоимость, рост характеристик и таблицу каждого следующего уровня. В блоке «Мой уровень и запасы» можно использовать последнюю копию подворья или ввести числа вручную. Пустой запас считается неизвестным. Кнопка «Максимум по запасам» учитывает оба ресурса и предел `min(40, уровень игрока + 2)`. Дух в охране усиливается после возвращения.

Расчёт не изменяет подворье и не тратит ресурсы. Усиление выполняется в самой игре.

## Пропуска на рейды

Каждому игроку нужен Пропуск. Один можно получить за первую за сутки раскрутку любого Древа-хранителя; у Офени — за 200 монет, до трёх покупок за сутки. Оплаченный Пропуск позволяет повторять бой с тем же боссом до победы или ухода босса. Выход из лобби не возвращает Пропуск. Подробнее — в справке приложения.

Токен аккаунта зашифрован ключом из Android Keystore и не передаётся в JavaScript. Приложение запрашивает только разрешение INTERNET. Оно получает список духов по вашей кнопке и не выполняет игровые действия.

## Запуск на компьютере

Установите [Node.js 20 или новее](https://nodejs.org/), затем в папке проекта выполните:

```sh
npm start
```

Откройте <http://127.0.0.1:8765>. Сторонние пакеты npm не требуются. Веб-версия содержит симулятор; подключение подворья по коду доступно в Android-приложении.

## Разработка

```sh
npm test
npm run build:android
```

Для сборки APK нужны JDK и Android SDK; настройка описана в [инструкции](docs/BUILD.md). Все исходники, необходимые для сборки, находятся в этом репозитории.

Структура проекта:

```text
android/app/src/main/    Android WebView, аккаунт, локальные ресурсы
android/app/src/debug/   Инструментальные проверки на тестовых данных
android/web/             Мобильная компоновка и мост к Android
web/                     Симулятор, каталоги, интерфейс и тесты
tools/                   Сборка и проверка проекта
docs/                    Документация
```

Симуляция даёт оценку при выбранных параметрах рун, темпе и состоянии команд. Реальный результат зависит от действий игроков и изменений игры. Каталог, номера летописи, боевые параметры, зелья, таблицы усиления и правила пропусков проверены с Mifozov 0.46.
